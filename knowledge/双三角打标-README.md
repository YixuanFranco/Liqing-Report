# 双三角六角打标 · 规范

## 这个目录是干什么的

熠瑄的方法论：**「先抓取一波 → 按双三角落位 → 再扒一遍 → 就完全理解了。」**
WorkBuddy 每天把 GitHub Trending 翻成人话（`日报/`，原料层）；
**打标层**用双三角六角把每个项目定位到「它补强/依赖哪个角」——让榜单从「哪些工具火」
变成「**当下 AI 浪潮在补哪个角、人侧角还剩几个在涨**」。

## 四个目录的关系（别搞混）

| 层 | 目录 | 谁写 | 节奏 |
| --- | --- | --- | --- |
| 原料 | `日报/` | 自动任务 | 每天，**不打标**（只作证据追溯） |
| **判断层（本目录）** | `提炼/双三角打标/` | 豆包 | 每批榜单打一次，首批见 [`2026-10-13-首批打标.md`](2026-10-13-首批打标.md) |
| 聚合层 | `主题/` | 自动任务 | 每 3 天，按话题跨时间聚合 |
| 知识层 | `沉淀/` | 人 / 对话 | 按需，与 GitHub 无关的长期知识 |

> 打标层是 2026-10-13 新加的，夹在「原料」和「聚合」中间：
> 主题聚合不碰打标，打标也不改日报——三层各管各的，避免互相踩。

## 六角标签表（与 F03 严格一致）

**人类三角**（人的能力，靠练）：

| 角 | 子项（F03 原文） | 判断问句 |
| --- | --- | --- |
| `【创造力】` | 理解底层规律 / 解放思想 / 提出创造假设 | 它在帮人「提出新解法、新假设」吗？ |
| `【审美】` | 专业见识 / 最佳实践 / 评价标准 | 它在固化或提升「对结果质量的高水平判断」吗？ |
| `【体系】` | 科学体系思维 / 假设验证 / 稳定知识结构 | 它在沉淀「可复用、可验证的框架/结构」吗？ |

**AI 三角**（AI 的能力，靠配）：

| 角 | 子项（F03 原文） | 判断问句 |
| --- | --- | --- |
| `【场景】` | 业务拆解 / ROI 预判 / AI 打磨 / 组织部署 | 它把某个「具体业务场景」交给了 AI 吗？ |
| `【基本功】` | 基础：LLM 提示词/智能体 ｜ 宽度：多模态/工具库 ｜ 深度：微调/工程化 | 它在补 AI 的「模型/工具/工程」底座吗？ |
| `【数据】` | 非结构化 / 结构化 / 形成资产 | 它在把散数据变成「可用的结构化资产」吗？ |

## 标签语法

- 每个项目：**1 个主角 + ≤2 个次角**，形如 `【主:场景】【次:基本功】【次:数据】`
- **每角必须给 1 句理由**（为什么是它，不是猜）
- **打不出来就写 `【—】`**：宁可承认打不出，也不硬凑——硬凑会把能力地图变成贴纸墙
- 打标时先过 Y 模型 Step1：「它解决什么**真实问题**」，再落到六角；理由句就是 Step1 的答案

## 空角观察（每批必写）

每批打标做完主角分布统计后，**0 主角（或连续两批低主角）的角必须写一段观察**，回答两个问题：

1. **是判断偏好，还是真没有？** —— 是我打标时没往那个角想（判断盲区），还是榜单真没有项目补它（市场事实）
2. **意味着什么 + 去哪补** ——
   - **人侧角 0 主角** → 没人替你练，只能自己练：去 [`F04 武器库`](../秋马卡片/框架/F04-双三角竞争力武器库.md) 取该角修炼路线
   - **AI 侧角 0 主角** → 工具还没长出来或没上榜：去 [`主题/`](../../主题/README.md)、[`提炼/外部工具/`](../外部工具/) 主动找

输出格式：每批打标文件末尾加 `## 空角观察 · <批次>` 小节，逐角写（角名 / 主角数 / 观察 / 应对）。
首批观察见 [`2026-10-13-首批打标.md`](2026-10-13-首批打标.md) 末节。

## 本批结论（2026-10-13 首批，9 条）

- 主角 **6/9 落在 AI 三角**（场景 3 / 基本功 3），人类侧 3 个（审美 2 / 创造力 1，明细见下）
- 读法：当前 trending 是「**放大器浪潮**」——多数项目在让现有模型干更多活，
  **人类的审美/创造力/体系角没有项目替你补，只能自己练**（这正是双三角存在的意义）
- 明细见 [`2026-10-13-首批打标.md`](2026-10-13-首批打标.md)
