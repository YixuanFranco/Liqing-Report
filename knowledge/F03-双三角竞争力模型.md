# 双三角 · AI 时代的竞争力模型

![双三角竞争力模型](../../../一堂/2026秋马-AI十倍速成长/P1/images/094.png)

**人类三角 × AI 三角**，中间是双向箭头：

- 向右：**人变强了，调教更强 AI**
- 向左：**有了强 AI，辅助人变得更强**
- 人类三角 = 持续让自己变强；AI 三角 = 持续使用 AI 更强

## 两句「灵魂拷问」

> 同样都会用 AI，为什么不同人**业务结果**相差这么大？（人类侧）
>
> 同样都是业务高手，为什么不同人 **AI 结果**相差这么大？（AI 侧）

## 人类三角

| 人类三角 | 子项 |
| --- | --- |
| **创造力** | 理解底层规律 / 善于解放思想 / 提出创造假设 |
| **审美** | 专业见识 / 最佳实践 / 评价标准 |
| **体系** | 科学体系思维 / 假设验证模型 / 稳定知识结构 |

## AI 三角

| AI 三角 | 子项 |
| --- | --- |
| **场景** | 业务拆解 / ROI 预判 / AI 打磨 / 组织部署 |
| **基本功** | 基础：LLM 提示词/智能体 ｜ 宽度：多模态/AI 工具库（∞）｜ 深度：模型微调训练/工程化 |
| **数据** | 非结构化数据 / 结构化数据 / 形成资产 |
