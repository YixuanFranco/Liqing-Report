# 一堂 Y 模型：无限进步画布

![Y 模型无限进步画布](../../../一堂/2026秋马-AI十倍速成长/P2/images/051.jpg)

前面几轮只能从逐字稿的只言片语描述 Y 模型（「往下找规律，把理论和事实放在一起」）。**完整画布长这样**，是一张可以直接打印填写的空白模板：

```
                    ┌ 自己建模型 ┐ ┌ 提出新假设 ┐
              理论  └───────────┘ └───────────┘  事实
   ┌──────────────┐        ↑↓         ↑↓        ┌──────────────┐
   │ 使用现成      │         ╲         ╱         │ 如何定性      │
Step3 模型/规律    │          ╲       ╱          │ 定量分析      │
   └──────────────┘           ╲     ╱           └──────────────┘
                          我的 ____ 认知
                                ↑                ┌──────────────┐
                             Step2               │ 理解因：      │
                                ↑                │ 我的框架(1-5条)│
                                ↑                └──────────────┘
                                ↑                ┌──────────────┐
                    Step1  解决真正问题           │ 理解果：      │
                                                 │ 我的目标(TopN) │
                                                 └──────────────┘
   ┌─────────────────────────────────────────────────────────┐
Step4 ∴ 配套的组织和管理工具：                                  │
   └─────────────────────────────────────────────────────────┘
```

## 四步的顺序值得注意，是从下往上

- **Step1 解决真正问题** —— 起点在最底部，**不是先找理论**
- **Step2 我的 ____ 认知** —— 中间的填空处，右侧配两格：「理解因：我的框架（1-5 条）」和「理解果：我的目标（TopN）」
- **Step3 理论 ⇄ 事实** —— 双向箭头同时往认知汇聚。左侧「使用现成模型/规律」，右侧「如何定性定量分析」，顶部两格是升级动作：**自己建模型**、**提出新假设**
- **Step4 ∴ 配套的组织和管理工具** —— 底部通栏，用「∴」（所以）符号引出

## 和双三角的关系

这解释了课程里那句「花辣子米走过的既是双三角，也是 Y 模型」：

- **Y 模型**管的是**怎么把真问题变成可靠认知**
- **双三角**管的是**人机怎么分工**
